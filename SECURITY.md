# Security

Please use GitHub’s private vulnerability reporting for security issues. Do not post keys, transcripts, or exploit details in a public issue.

This preview sends prompts, final replies, and local tool inputs and outputs to the gateway selected during setup. Recording is opt-in. Its redaction is not a complete secret detector; use it only for conversations you intend to share with that gateway.

The repository does not need your credentials to run its automated tests. Never include API keys, local state directories, or real conversation data in pull requests.
